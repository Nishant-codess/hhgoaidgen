# Hacker House Goa 2026 — Builder Pass Generator

This is a local ID generator for Hacker House Goa 2026. It allows you to create customizable, deterministic, and highly polished Builder Passes that can be downloaded and shared on X with `#FrameInGoa`.

## Prerequisites
- Node.js (v18+)
- npm or yarn

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Nishant-codess/hhgoaidgen.git
   cd hhgoaidgen
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```
   *or if you are using yarn:*
   ```bash
   yarn install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Open your browser and navigate to the URL provided in your terminal (usually `http://localhost:5173/`).

## Features
- **Deterministic ID Generation**: IDs and Barcodes are deterministically generated from your GitHub handle.
- **Themes**: Choose between a **Light Beach Passport** and a **Neon Cyberpunk** theme.
- **Export**: Easily save your builder pass as a PNG to your device.
